# Flat exploration v2

15 pilots generated using the built-in image generation tool: five heroes, five R/economics cards, and five temporary dashboard studies.

Open `index.html` for the comparison gallery. Original PNGs and WebP previews are saved alongside `prompts.json`, which records every exact prompt. Heroes are exported at 2400 × 1000; cards at 1536 × 1024, WebP quality 85.

The current flat-art brief governed this batch. Site image references remain unchanged.

Review notes: the roundness and light blue/green vocabulary are consistent, but some fills have subtle tonal variation rather than perfectly uniform color. Economics 03 has a mismatched enlargement; Economics 01 and 04 contain residual correspondence problems. Dashboard 05 does not clearly encode rank. These are experiments, not approved instructional figures. Actual desktop/mobile page crops remain untested.

Promising starting points: hero 01 for openness, hero 02 for bolder geometry, economics 02 and 05 for single-figure clarity, dashboard 01 and 02 for coordinated views.
